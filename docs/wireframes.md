## Florist catalogue

```text
mobile: intro -> horizontal filter chips -> result count -> 2-col cards
desktop: wide intro -> sticky filter rail (3 cols) -> dense cards (9 cols)
detail: image gallery -> sample metadata -> disclaimer -> use as inspiration
```

## Bouquet builder

```text
┌─────────────────────────────┐
│ Back  Customise       3/12  │
│ progress bar                │
├─────────────────────────────┤
│ Step title and guidance     │
│                             │
│ large option cards/chips    │
│ ranked sample cards         │
│ or labelled form fields     │
│                             │
├─────────────────────────────┤
│ [Back]          [Continue]  │
└─────────────────────────────┘
```

Desktop keeps the builder in an 8-column work area and a sticky 4-column live summary. All steps remain addressable by keyboard and the browser back button.

## Café and selection

```text
café: category rail -> product grid -> option bottom sheet -> add to selection
selection: bouquet summary -> café line items -> fulfilment form -> disclaimers
           -> consent checkbox -> save and open WhatsApp
```

## Admin

```text
mobile: compact masthead -> metric cards -> priority enquiries -> nav drawer
desktop: fixed 260px nav -> title/actions -> metrics -> table/forms
resource forms: grouped fields, sticky save bar, inline errors, audit context
```

Tables collapse into labelled record cards on narrow screens; destructive actions never appear as unlabeled icons.
